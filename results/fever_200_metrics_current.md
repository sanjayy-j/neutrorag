# FEVER failure-type attribution: NeutroRAG vs. raw NLI baseline

N = 200 claims, `copenlu/fever_gold_evidence` validation split, scored with `MoritzLaurer/DeBERTa-v3-base-mnli-fever-anli`.

Source: `fever_run_200_current.csv` | generated by `python experiments/make_results_table.py` | commit `a79f5ae`

Both systems use the **identical** NLI calls. The baseline takes `argmax` over the NLI head's own distribution (e->T, n->I, c->F); NeutroRAG takes `argmax` over the (T, I, F) triple built from it.
